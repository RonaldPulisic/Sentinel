**Sentinel** is a security console that brings your tools, threat intelligence, cheat sheets, a code workbench, and local AI into one place. It comes in two forms that share the same identity and design:

- A **web console** you sign into from any browser.
- A **desktop app** (Linux, Windows) that's far more powerful — it runs real tools, live terminals, a full code editor, and talks to your local AI models.

## What you can do

- **Curated tools** — 80\+ security tools with copy-paste install commands, plus in-browser utilities (encoders, hashes, payloads).
- **Threat intel** — notable CVEs, a common-ports attack-surface map, and a security-posture checklist.
- **Cheat sheets** — battle-tested one-liners for recon, shells, privesc, and cracking, with one-click copy.
- **Code workbench** — a real editor, file tree, run-code, and an integrated terminal (desktop app).
- **Payloads & handlers** — reverse shells, listeners, and msfvenom payloads from live builders.
- **Local AI** — chat and code with private Ollama models; nothing leaves your machine.

## Get started

- [**Quickstart**](/quickstart) — sign in and run your first scan.
