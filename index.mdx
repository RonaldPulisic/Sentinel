  **Sentinel** is a security console that brings your tools, threat
  intelligence, cheat sheets, a code workbench, and local AI into one place. It
  comes in two forms:

  - A **web console** you sign into from any browser.
  - A **desktop app** (Linux, Windows) that runs real tools, live terminals, a
  full code editor, and your local AI models.

  ## What you can do

  - **Curated tools** — 80+ security tools with copy-paste install commands,
  plus in-browser utilities.
  - **Threat intel** — notable CVEs, a common-ports attack-surface map, and a
  posture checklist.
  - **Cheat sheets** — one-liners for recon, shells, privesc, and cracking, with
  one-click copy.
  - **Code workbench** — a real editor, file tree, run-code, and an integrated
  terminal.
  - **Payloads & handlers** — reverse shells, listeners, and msfvenom payloads
  from live builders.
  - **Local AI** — chat and code with private Ollama models; nothing leaves your
  machine.

  ## Get started

  Head to the [Quickstart](/quickstart) to sign in and run your first scan.

  > **Authorized use only.** Sentinel is for security testing and defensive work
  on systems you own or are permitted to test.
