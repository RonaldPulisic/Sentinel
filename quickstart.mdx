  Sentinel has two parts. Start with the **web console** to sign in, then
  install the **desktop app** to run tools locally.

  ## Prerequisites

  - A modern browser (Chrome, Edge, Firefox, or Safari).
  - A Google account, a GitHub account, or any email address.
  - **For running tools locally:** a Linux machine (Kali/Parrot/Ubuntu) or
  Windows, plus the desktop app.
  - **For local AI (optional):** [Ollama](https://ollama.com) installed and
  running.

  ## Sign in to the web console

  1. Open Sentinel and choose **Get Started**.
  2. Continue with **Google**, **GitHub**, or an **email and password** (email
  accounts get a verification link).
  3. You land on the dashboard. Use the sidebar for **Tools**, **Cheat sheets**,
  **Threat intel**, and **Settings**. Press `Ctrl` / `Cmd` + `K` to search.

  ## Install the desktop app

  **Linux (.deb — Debian, Ubuntu, Kali):**

  ```bash
  sudo apt install ./Sentinel-linux.deb

  Then launch Sentinel from your app menu, or run sentinel.

  Linux (AppImage — any distro):

  chmod +x Sentinel-linux.AppImage
  ./Sentinel-linux.AppImage

  The AppImage needs FUSE: sudo apt install libfuse2.

  Windows: double-click Sentinel-windows.exe. If SmartScreen warns, choose More 
  info → Run anyway.

  Run your first scan

  1. Type an IP or domain into the TARGET bar — every tool command uses it
  automatically.
  2. Open Tools and expand one (e.g. Nmap), or open Playbooks and run Quick 
  recon.
  3. Output streams into a terminal. Turn on Save output in Settings to log runs
  to ~/sentinel-results, then browse them under Loot.

  ▎ Only scan targets you are authorized to test.
