---
  title: "Quickstart"
  description: "From zero to your first scan in a couple of minutes."
  ---

  Sentinel has two parts. Start with the **web console** to sign in and explore,
  then install
  the **desktop app** when you want to actually run tools and terminals locally.

  ## Prerequisites

  - A modern browser (Chrome, Edge, Firefox, or Safari).
  - A Google account, a GitHub account, or any email address (for email +
  password sign-up).
  - **For running tools locally:** a Linux machine (Kali/Parrot/Ubuntu
  recommended) or Windows,
    and the desktop app.
  - **For local AI (optional):** [Ollama](https://ollama.com) installed and
  running.

  ## Sign in to the web console

  <Steps>
    <Step title="Open Sentinel">
      Go to your Sentinel URL and choose **Get Started**.
    </Step>
    <Step title="Create an account">
      Continue with **Google**, **GitHub**, or sign up with an **email +
  password**.
      Email/password accounts receive a verification link — open it, then
  reload.
    </Step>
    <Step title="Explore the console">
      You land on the dashboard. From the sidebar you can reach **Tools**,
  **Cheat sheets**,
      **Threat intel**, **Learn**, and **Settings**. Press
  <kbd>Ctrl</kbd>/<kbd>⌘</kbd> +
      <kbd>K</kbd> anywhere to search.
    </Step>
  </Steps>

  <Tip>
    The web console is great for references and in-browser utilities, but it
  can't run tools on
    your machine — that's what the desktop app is for.
  </Tip>

  ## Install the desktop app

  <Tabs>
    <Tab title="Linux (.deb)">
      Recommended for Debian, Ubuntu, and Kali.

      ```bash
      sudo apt install ./Sentinel-linux.deb
      ```

      Then launch **Sentinel** from your application menu, or run `sentinel` in
  a terminal.
    </Tab>
    <Tab title="Linux (AppImage)">
      Portable — works on any distro.

      ```bash
      chmod +x Sentinel-linux.AppImage
      ./Sentinel-linux.AppImage
      ```

      The AppImage needs FUSE: `sudo apt install libfuse2` (or run it with
      `--appimage-extract-and-run`).
    </Tab>
    <Tab title="Windows">
      Double-click **Sentinel-windows.exe**. If SmartScreen warns, choose
      **More info → Run anyway** (the installer is unsigned).
    </Tab>
  </Tabs>

  ## Run your first scan

  <Steps>
    <Step title="Set a target">
      In the desktop app, type an IP or domain into the **TARGET** bar at the
  top. Every tool
      command substitutes it automatically.
    </Step>
    <Step title="Pick a tool or playbook">
      Open **Tools** and expand one (e.g. Nmap), or open **Playbooks** and run
  **Quick recon**
      to chain several scans in one terminal tab.
    </Step>
    <Step title="Read (and save) the output">
      Output streams into an interactive terminal. Turn on **Save output** in
  Settings to log
      every run to `~/sentinel-results`, then browse them under **Loot**.
    </Step>
  </Steps>

  <Warning>
    Only scan targets you are authorized to test. See [Responsible
  use](/responsible-use).
  </Warning>
