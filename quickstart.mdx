Sentinel has two parts. Start with the **web console** to sign in and explore, then install the **desktop app** when you want to run tools and terminals locally.

## Prerequisites

- A modern browser (Chrome, Edge, Firefox, or Safari).
- A Google account, a GitHub account, or any email address (for email and password sign-up).
- **For running tools locally:** a Linux machine (Kali, Parrot, or Ubuntu recommended) or Windows, plus the desktop app.
- **For local AI (optional):** [Ollama](https://ollama.com) installed and running.

## Sign in to the web console

1. Open Sentinel and choose **Get Started**.
2. Continue with **Google**, **GitHub**, or sign up with an **email and password**. Email and password accounts get a verification link. Open it, then reload.
3. You land on the dashboard. Use the sidebar to reach **Tools**, **Cheat sheets**, **Threat intel**, **Learn**, and **Settings**. Press `Ctrl` / `⌘` + `K` anywhere to search.

The web console is great for references and in-browser utilities, but it can't run tools on your machine. That's what the desktop app is for.

## Install the desktop app

### Linux (.deb, recommended for Debian, Ubuntu, Kali)

```bash
sudo apt install ./Sentinel-linux.deb
```

Then launch Sentinel from your app menu, or run `sentinel`.

### Linux (AppImage, any distro)

```bash
chmod +x Sentinel-linux.AppImage
./Sentinel-linux.AppImage
```

The AppImage needs FUSE. Install it with `sudo apt install libfuse2`, or run the AppImage with `--appimage-extract-and-run`.

### Windows

Double-click `Sentinel-windows.exe`. If SmartScreen warns, choose **More info** → **Run anyway**. The installer is unsigned.

## Run your first scan

1. In the desktop app, type an IP or domain into the **TARGET** bar at the top. Every tool command substitutes it automatically.
2. Open **Tools** and expand one (for example, Nmap), or open **Playbooks** and run **Quick recon** to chain several scans in one terminal tab.
3. Output streams into an interactive terminal. Turn on **Save output** in **Settings** to log every run to `~/sentinel-results`, then browse them under **Loot**.

> **Only scan targets you are authorized to test.**
